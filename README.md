# Airsoft Operating System 3.9.0 — Resizable Dashboard

This release adds genuine widget resizing to the existing AOS desktop, especially
System Status. It includes the 3.8.2 stylesheet startup fix.

## Usage
1. Log in to AOS and click the **pencil** in the left sidebar (EDIT).
2. Drag a widget by its **title** to move it.
3. Drag the **red lower-right corner** to resize it; System Status can be as small
   as approximately 165 × 145 pixels, depending on its contents and current screen.
4. Right-click a widget in EDIT mode for **Compact / Standard / Large** size presets.
5. Click the pencil again to leave EDIT mode; your layout is saved automatically.

System gauges resize responsively and the long CPU description hides in compact
mode. Live CPU/RAM/DISK/BATTERY percentages remain visible as four circles.

## Installation / first-time upgrades
Extract the archive and run: `sudo bash linux/install.sh`.
This keeps the old AOJ login entries redirected to the current AOS and retains
user data under `~/.config/aoj-os`.

## Update via GitHub
Use the signed release assets generated by `release_tools/build_release.py`.
Remote AOS update packages contain only the allowed application files; they do
not run scripts as root, change Debian system configuration or overwrite user data.
See `GITHUB_RELEASE.md` for upload and update instructions.

## Limitations
- Full Qt GUI tests require a Linux X11 desktop and PySide6; this build has not
  been tested on a physical Panasonic Toughbook CF-19.
- The remote updater cannot alter its own privileged installation policy.
- GitHub repository writes/publishing require authorised account access.
