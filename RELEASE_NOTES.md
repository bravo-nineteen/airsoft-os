## AOS 3.9.0 — Resizable Tactical Dashboard

- Added draggable resize handles for desktop widgets in EDIT mode.
- Added right-click Compact, Standard and Large size presets.
- Made CPU, RAM, Disk and Battery circular gauges responsive to small panels.
- Preserved existing 3.5+ home-screen widget positions and sizes across upgrades.
- Kept high-contrast dark theme and AOS 3.8.2 startup stylesheet fix.
- Compatible with signed releases from bravo-nineteen/airsoft-os.

**Before updating:** Back up your existing settings. Requires the existing AOS
updater and a trusted Ed25519 public key. Keep the Debian fallback session.
